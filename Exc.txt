1) Переменная создаётся через =: price = 8990.0. Типы: int, float, str, bool, плюс список, словарь, кортеж.
2) print выводит на экран, input принимает ввод с клавиатуры (всегда строкой).
3) for перебирает элементы коллекции, while работает, пока условие истинно.
4) range(5) даёт 0, 1, 2, 3, 4. range(1, 6) даёт 1, 2, 3, 4, 5.
5) Список хранит элементы по порядку (доступ по индексу), словарь хранит пары «ключ: значение» (доступ по ключу).
6) Кортеж это неизменяемый список, удобен для фиксированных данных, например (36.0, 5).
7) products.sort(key=lambda p: p['price']) или sorted(products, key=lambda p: p['price']).
8) lambda это короткая безымянная функция в одну строку.
9) [p for p in products if p['price'] < 8000].
10) return завершает функцию и возвращает результат (без него вернётся None).
